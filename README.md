# notes-api

A REST API for private personal notes by **MR Ransaz**.
Repository: [mr-ransaz/notes-api](https://github.com/mr-ransaz/notes-api).
Version: 0.1.0. Python: 3.14.x.

Stages 1 and 2 implement registration, password login, current user, health,
and private notes CRUD with pagination and literal substring search.
Full usage and deployment documentation is added with stage 3.
